# Invention Project Management System 🚀

ระบบจัดการโครงการสิ่งประดิษฐ์ (Invention Project Management System) สำหรับบริหารจัดการและจัดเก็บข้อมูลโครงการสิ่งประดิษฐ์อย่างเป็นระบบ

## 🛠 Tech Stack

* **Backend:** Node.js, Express.js
* **Frontend:** HTML5, Tailwind CSS
* **API Documentation:** Swagger UI
